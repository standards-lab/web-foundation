## Decisions

- adoption: Decisions and Pending edits were condensed by harness.adoption-web-foundation; the full
  earlier wording is this record at web-foundation bfe322b.
- plan: `standard` adds architecture to the goal's repos for that task only.
- plan: the catalog declares no `standard = "web-elemental"` until `standard` founds it; until
  then each entry cites the preliminary standard, web-client.md "Toward Web Elemental".
- plan: Firefox's missing `blocking="render"` is accepted (a one-frame theme flash for readers
  with a non-default stored theme); no inline head script. Revisit when Firefox ships it.
- plan: Safari's missing CSS module scripts mean a page using the components requires a Vite
  build; the packages keep the standard syntax, no pack-time rewrite. Revisit when Safari ships it.
- components: peer `@standards-lab/web-foundation` by caret; each foundation minor gets a
  components release that confirms it (round 1).
- template: this goal touches neither go-web-sdk-template nor go-web-service, nor the exclusive
  group (round 2 facts, round 3).
- template (round 1): a written project's lint enforces eslint-comments' `require-description`
  (plugin 4.8.1) and typescript-eslint's `ban-ts-comment` at allow-with-description; this settles
  the open web-client.md note for `standard`.
- components-settings: the app binds S and ?, as webappgen's starter does; no component binds a
  page key.
- components-settings: sl-drawer's `modal` replaces spike-html-go-wasm's `dock="10000rem"`
  stand-in for a drawer modal at every width.
- components-settings: sl-shortcuts exports its own screen-reader `NOTE`, since web-foundation
  v0.4.0 exports none; moving it into the foundation is a candidate for a later foundation task.
- components-settings: the layer-tree test names webappgen by a relative path into the sibling
  checkout (`../webappgen/...`), since webappgen has no npm name.
- embedded: rejected for new services: webappgen's own copy of go-web-sdk-template, and a go.mod
  `tool` directive for gonew. Rejected for the wiring: dave/dst and x/tools' astutil (the
  module's dependency rule).
- embedded: falsified that pnpm 12.23.0 changes nothing the starter adapts: it enforces
  `blockExoticSubdeps` against lockfiles. A written project passes; any `pnpm fetch` must run
  beside the project's `package.json`.
