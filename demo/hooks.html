Foundation hooks

The baseline's five color roles, hooks that no profile declares: each falls back to a hue of the palette, and a consumer sets one on any subtree.

Primary: --color-primary

What you can act on, by default --blue: links, checkboxes, radios, ranges, the focus outline, the caret, selected text, and the hover border of fields and buttons.

A link

Accent: --color-accent

What is current, active, or in progress, by default --magenta: native progress, at a value and indeterminate.

Success, warning, danger: --color-success, --color-warning, --color-danger

What went well, by default --green; what needs care, by default --orange; what fails or destroys, by default --red. No baseline rule reads them: this page reads each as a consumer does, var(--color-danger, var(--red)).
